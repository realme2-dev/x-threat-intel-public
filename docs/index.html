1. 현재 주요 사이버보안 트렌드


최근 사이버 위협 환경은 AI를 활용한 공격의 고도화와 함께, 공공기관 및 대규모 데이터 보유 기관을 대상으로 한 대규모 데이터 유출 사고가 빈번하게 발생하고 있습니다. 특히 macOS Screen Sharing 및 SharePoint와 같은 소프트웨어의 인증 우회 취약점이 활발히 악용되고 있으며, 공격자들은 PoC 공개 직후 신속하게 이를 실무 환경에 적용하고 있습니다 (TheHackerNews, BleepingComputer). 또한, 공급망 공격의 일환으로 악성 패키지 유포나 서비스 제공업체의 취약점을 노린 금융 사기 등 비즈니스 프로세스 전반을 겨냥한 공격이 지속되고 있습니다 (SecurityWeek).

2. 주요 위협 행위자 / 캠페인


- Lazarus Group: Windows Zero-Day 취약점을 악용하여 SYSTEM 권한을 획득하고 신규 백도어를 배포하는 정황이 포착됨 (TheHackerNews).
- HoneyMyte: CoolClient 백도어의 신규 변종을 배포하며, 커널 모드 rootkit 드라이버를 통해 보안 솔루션의 탐지를 회피함 (Securelist).
- Armored Likho: 기부 캠페인을 사칭하여 Still Toolkit을 배포, Telegram 데이터 탈취 및 도청 시도 (Securelist).
- Head Mare: TrueConf 서버의 취약점을 악용하여 PhantomCore 및 PhantomGraph 백도어를 배포 (Securelist).

3. 한국 관련 위협


- DragonForce: 한국 온라인 교육 기업 대상 랜섬웨어 공격 수행 (AhnLab ASEC).
- Qilin: 한국 모터 및 로봇 기계 제조 기업 대상 랜섬웨어 공격 수행 (AhnLab ASEC).
- 피싱 공격: 국내 정부기관 담당자를 대상으로 상품 파손 클레임을 사칭한 스피어피싱 메일 유포 및 정보 탈취 악성코드 배포 (이스트시큐리티 알약).

4. 주요 CVE / 취약점


- CVE-2026-15826: User Profile Builder (WordPress), CVSS 9.8, 인증 우회 및 관리자 계정 탈취 가능 (ThreatWire).
- CVE-2026-59310: VMware vCenter, CVSS 9.8, 원격 코드 실행 및 지속성 확보 가능 (infrasecserv).
- CVE-2026-55040: Microsoft SharePoint, 인증 우회 취약점, PoC 공개 후 악용 중 (TheHackerNews).
- CVE-2026-65400: macOS Screen Sharing, 인증 우회, Monero 채굴기 배포에 악용 (BleepingComputer).
- CVE-2026-42167: ProFTPD, CVSS 8.1, 패치 미적용 시 원격 코드 실행 위험 (zauthinc).
