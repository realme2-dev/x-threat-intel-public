1. 현재 주요 사이버보안 트렌드


최근 사이버 위협은 생성형 AI를 활용한 공격 자동화와 취약점 탐색이 고도화되는 양상을 보이며, 특히 AI 모델 자체의 취약점을 악용하거나 AI를 이용해 복잡한 공격 체인을 구성하는 사례가 증가하고 있습니다(TheHackerNews). 또한, 기업의 관리 서버 및 API 엔드포인트를 타겟으로 한 인증 우회 및 RCE 취약점이 다수 발견되어, 공급망 보안과 API 보안의 중요성이 극대화되고 있습니다(DarkReading). 마지막으로, 국가 지원 APT 그룹들은 기존의 악성코드 배포 방식에 더해 취업 사기, 클라우드 서비스 악용, 오픈소스 공급망 침해를 결합한 다각적 공격을 지속하고 있습니다(AhnLab ASEC).

2. 주요 위협 행위자 / 캠페인


  • WaterPlum: 구직자를 대상으로 한 취업 사기를 통해 암호화폐 탈취 및 정보 유출을 시도하며, 전 세계 3만 대 이상의 기기를 감염시킨 것으로 확인됨(CyberScoop).

  • FamousSparrow: 새로운 백도어인 SparroWocky를 사용하여 타겟 시스템에 대한 명령 실행 및 제어권을 확보하는 캠페인 수행(WeLiveSecurity).

  • NightEagle: GhostContainer 백도어와 GitHub 호스팅 도구를 활용하여 러시아 기업을 타겟으로 한 공격 수행(Securelist).

  • Toy Ghouls: HiveMQ MQTT 브로커 및 Matrix 프로토콜을 C2 서버로 활용하는 신규 백도어 캠페인 포착(Securelist).


    • 3. 한국 관련 위협


  • 국내 의료기관 랜섬웨어: RDP 취약점을 악용한 Beast(GodDamn) 랜섬웨어 공격이 국내 의료기관을 대상으로 발생(이스트시큐리티 알약).

  • 사설 HTS 랜섬웨어: 'UBP 에셋'이라는 사설 HTS 프로그램을 통해 랜섬웨어가 유포되는 사례 확인(AhnLab ASEC).

  • 피싱 메일: Slack의 정상적인 초대 기능을 악용한 회사 임원 사칭 피싱 메일이 국내 기업 대상으로 유포 중(이스트시큐리티 알약).
