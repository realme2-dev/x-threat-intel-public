🟡 위협 점수: 5/10 (보통)

1. 현재 주요 사이버보안 트렌드


최근 사이버 위협 환경은 AI를 활용한 취약점 탐색 및 공격 자동화가 가속화되면서, 공격자가 취약점 공개 직후 PoC를 악용하는 속도가 매우 빨라졌습니다 (TheHackerNews). 특히 'Agentic AI'를 활용한 자율적 공격 프레임워크가 등장하며, 기존의 정적 방어 체계를 우회하는 지능형 위협이 증가하고 있습니다 (이스트시큐리티 알약). 또한, 공급망 공격 및 API 취약점을 노린 데이터 유출 사고가 빈번하며, 기업들은 양자컴퓨터 시대에 대비한 암호 체계 전환(PQC)을 로드맵에 포함하기 시작했습니다 (데일리시큐).

2. 주요 위협 행위자 / 캠페인


- Lazarus Group: Windows Zero-Day 취약점을 악용하여 SYSTEM 권한을 획득하고 신종 백도어를 배포함 (TheHackerNews).
- HoneyMyte: CoolClient 백도어의 신규 변종을 배포하며, 커널 모드 rootkit을 통해 보안 도구의 탐지를 회피함 (Securelist).
- Armored Likho: 기부 캠페인을 사칭하여 Telegram 데이터 탈취 및 도청을 수행하는 Still Toolkit을 유포함 (Securelist).
- Head Mare: TrueConf 서버 취약점을 악용하여 PhantomCore 및 PhantomGraph 백도어를 유포함 (Securelist).

3. 한국 관련 위협


- 랜섬웨어 공격: DragonForce가 한국 온라인 교육 기업을, Qilin이 한국 모터 및 로봇 제조 기업을 대상으로 랜섬웨어 공격을 수행함 (AhnLab ASEC).
- 피싱 메일: 정부기관 담당자를 대상으로 상품 파손을 사칭한 스피어피싱 메일이 유포됨 (이스트시큐리티 알약).
- 기타: 한국어 트윗([KR])에서 MITRE ATT&CK 기반의 보안 분석 및 AI 에이전트용 보안 스킬셋에 대한 논의가 활발히 감지됨 (트윗 링크).
