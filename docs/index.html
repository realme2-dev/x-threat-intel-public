1. 현재 주요 사이버보안 트렌드


최근 사이버 위협 환경은 AI 모델의 고도화와 함께 공격자의 자동화된 악용 사례가 급증하고 있으며, 특히 'Agentic AI'를 활용한 공격이 생산성을 높이는 단계로 진화하고 있습니다 (이스트시큐리티 알약). 또한, 공개된 PoC를 즉각적으로 악용하는 'Zero-day' 공격 주기가 매우 짧아졌으며, 공급망 공격과 더불어 취약한 브라우저 확장 프로그램을 통한 트래픽 가로채기 및 데이터 탈취가 광범위하게 발생하고 있습니다 (TheHackerNews). 기업 환경에서는 API 보안 취약점과 클라우드 설정 오류(CSPM)가 주요 공격 경로로 활용되고 있어 실시간 가시성 확보가 필수적인 상황입니다 (Qualys Blog).

2. 주요 위협 행위자 / 캠페인


- Lazarus Group: Windows Zero-day 취약점을 악용하여 SYSTEM 권한을 획득하고 신규 백도어를 배포하는 캠페인 수행 (TheHackerNews).
- HoneyMyte: 'CoolClient' 백도어의 신규 변종을 배포하며, 커널 모드 rootkit을 통해 보안 도구로부터 프로세스와 네트워크 연결을 은폐 (Securelist).
- Armored Likho: 기부 캠페인을 사칭하여 'Still Toolkit'을 배포, Telegram 데이터 탈취 및 도청 시도 (Securelist).
- Head Mare: 패치되지 않은 TrueConf 서버 취약점을 악용하여 'PhantomCore' 및 'PhantomGraph' 백도어 배포 (Securelist).

3. 한국 관련 위협


- 랜섬웨어 공격: DragonForce가 한국 온라인 교육 기업을, Qilin이 한국 모터 및 로봇 기계 제조 기업을 대상으로 랜섬웨어 공격을 수행함 (AhnLab ASEC).
- 피싱 메일: 국내 정부기관 담당자를 대상으로 상품 파손 클레임을 사칭한 스피어피싱 메일이 유포됨 (이스트시큐리티 알약).
- 기타: 국세 당국을 사칭한 세무 위반 통지 피싱 메일을 통해 원격제어 악성코드가 유포됨 (이스트시큐리티 알약).

4. 주요 CVE / 취약점


- CVE-2026-72898: Metabase SQL Injection, CVSS 10.0, 현재 악용 중 (HunterMapping)
- CVE-2026-59310: VMware vCenter RCE, CVSS 9.8, 글로벌 위협 캠페인 진행 중 (DarkReading)
- CVE-2026-58626: Windows Remote Desktop Services RCE, CVSS 8.8 (Teeeda_worker)
- CVE-2026-55040: Microsoft SharePoint Authentication Bypass, 악용 시작됨 (TheHackerNews)

6. 즉각 대응 권고


- 패치 우선순위: CVE-2026-72898(Metabase) 및 CVE-2026-59310(VMware vCenter)에 대한 즉각적인 패치 적용.
- 확장 프로그램 점검: 조직 내 브라우저에서 사용 중인 VPN/Proxy 확장 프로그램 전수 조사 및 불필요한 확장 프로그램 제거.
- 피싱 대응: 정부기관 및 세무 당국 사칭 메일에 대한 모니터링 강화 및 임직원 대상 보안 교육 실시.
