1. 현재 주요 사이버보안 트렌드


최근 사이버 위협은 AI 에이전트를 활용한 공격 자동화와 공급망 공격(Supply Chain Attack)의 결합으로 인해 공격 속도와 규모가 비약적으로 증가하고 있습니다. 특히 Optimizely와 같은 서드파티 플랫폼을 악용한 대규모 악성코드 유포 사례가 보고되었으며, Java4Shell(CVE-2026-114938)과 같은 치명적인 RCE 취약점이 발견되어 기업 인프라에 즉각적인 위협이 되고 있습니다(TheHackerNews). 또한, AI 모델 자체의 취약점이나 백도어(LoRA 모델 등)를 이용한 공급망 공격이 새로운 보안 화두로 떠오르고 있습니다(Crowdstrike Blog).

2. 주요 위협 행위자 / 캠페인


- Trigram: 유럽 및 미국의 AI, 블록체인, 물류 분야를 타겟으로 하는 대규모 인포스틸러(Infostealer) 유포 캠페인(TheHackerNews).
- Turla: Cereal 툴셋을 사용하여 Exchange 서버를 타겟으로 이메일 수집 및 고도화된 C&C 통신 수행(WeLiveSecurity).
- CopperDragon: 아시아, 라틴 아메리카, 유럽의 고위급 조직을 대상으로 Sparrow 프레임워크를 활용한 침투 활동(Check Point Research).

3. 한국 관련 위협


- S2W 보고서: 텔레그램 및 다크웹 내 AI 시험 부정행위 관련 장비와 수법 유통 실태 포착(데일리시큐).
- 스미싱 유포: Pi Network 보상을 미끼로 한 피싱 및 악성 앱 유포 사례 확인(이스트시큐리티 알약).
- 핵티비스트 활동: 친러 성향 핵티비스트 그룹이 북한 지역 정부 및 공공기관을 타겟으로 활동 중(AhnLab ASEC).

4. 주요 CVE / 취약점


- CVE-2026-114938: OpenJDK Base64 디코더 메모리 손상(RCE), CVSS 9.2, 악용 중(Qualys Blog).
- CVE-2026-125350: Google Chrome libxslt 메모리 해제 후 재사용(UAF), 악용 중(이스트시큐리티 알약).
- CVE-2026-111497: Node.js Brotli 디코더 취약점(Node2Shell), 심각(CISA ICS Advisories).

5. IOC 요약

- Java 환경 점검: CVE-2026-114938 대응을 위해 즉시 OpenJDK 보안 패치를 적용하고, 외부 노출된 Java 애플리케이션의 트래픽을 모니터링하십시오.
- 공급망 보안 강화: 서드파티 스크립트(Optimizely 등)를 사용하는 웹 사이트의 무결성을 검증하고, 외부 스크립트 실행에 대한 엄격한 세그먼테이션을 적용하십시오.
- 클라우드 자산 관리: Docker Hub 등 공개 저장소에 클라우드 자격 증명(API Key 등)이 노출되지 않았는지 확인하고, 노출 즉시 키를 교체하십시오.
