1. 현재 주요 사이버보안 트렌드


최근 사이버 위협 환경은 AI를 활용한 공격 자동화와 고도화가 핵심 트렌드로 자리 잡았습니다. 특히 Chinese state-sponsored threat actors가 AI 기반 침투 테스트 프레임워크인 ARTEX를 사용하여 전 세계 200개 이상의 조직을 공격하는 등 공격 속도와 정밀도가 비약적으로 상승했습니다(TheHackerNews). 또한, 웹 백엔드 런타임(PHP, Node.js)의 취약점을 악용한 PHP2Shell 공격이 지속되고 있으며, 공급망 공격의 일환으로 개발자 도구(Cursor IDE의 Claude Code extension)를 변조하여 백도어를 심는 사례가 보고되었습니다(BleepingComputer).

2. 주요 위협 행위자 / 캠페인


- Vapor Panda (China-backed): ARTEX 프레임워크를 활용해 11일 만에 14개국 140개 이상의 민감한 타겟을 공격(CyberScoop).
- Lazarus Group (North Korea): Binance에서 약 $6.3 billion 규모의 암호화폐를 탈취하는 등 대규모 금융 공격 지속(Malwarebytes Labs).
- ShinyHunters: FBI 데이터 유출 사건과 연루되어 있으며, 랜섬웨어 협상가를 가장한 활동이 포착됨(Krebs on Security).

3. 한국 관련 위협


- 더존비즈온: 백업 서버 침해 사고로 인해 아산·천안충무병원 등 거래처의 개인정보 유출 가능성 제기(데일리시큐).
- GS건설: 자이(Xi) 고객 개인정보(비밀번호, RF카드번호 등) 유출 사고 발생(데일리시큐).
- 머니투데이: 개인정보 유출 사고가 동행미디어 시대 등 위탁 언론사로 확산(데일리시큐).
- C3RB3R 랜섬웨어: 시놀로지 NAS를 타겟으로 국내외에서 집중 유포 중(이스트시큐리티 알약).

4. CVE-2026-91403: Oracle Java SE/GraalVM TLS 구현, 인증서 검증 우회, 긴급 패치 권고(이스트시큐리티 알약).
