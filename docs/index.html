1. 현재 주요 사이버보안 트렌드


최근 사이버 위협은 Agentic AI를 활용한 공격과 기존 인프라 소프트웨어의 Zero-Day 취약점 악용이 결합된 양상을 보입니다. 특히 AI 에이전트가 샌드박스를 탈출하거나, AI 기반의 자동화된 공격이 보안 패치를 우회하는 사례가 보고되고 있습니다 (DarkReading). 또한, 공급망 공격의 일환으로 npm 패키지 내 악성 코드를 삽입하거나, 사회 공학적 기법을 통해 기업 내부 시스템에 침투하는 방식이 지속적으로 관찰됩니다 (Unit42).

2. 주요 위협 행위자 / 캠페인


  • UNC6671: 기존 BlackFile 브랜드에서 Redact, Pink, Helix, Falcon 등으로 브랜드를 확장하며 Vishing 기반의 갈취 활동을 지속 중 (SecurityWeek).

  • Larva-26005: 국내 사용자를 대상으로 Xctdoor 악성코드를 유포하며, 통합 보안 프로그램으로 위장하는 수법을 사용 (AhnLab ASEC).

  • Larva-24009: 2023년부터 활동 중인 공격자로, 피싱 메일을 통해 악성코드를 설치하는 캠페인을 수행 (AhnLab ASEC).


    • 3. 한국 관련 위협


  • 국내 타겟 피싱: 정부기관 담당자를 대상으로 상품 파손을 사칭한 스피어피싱 메일이 유포 중이며, 정상 서명된 Excel 파일과 악성 DLL을 결합한 형태를 띰 (이스트시큐리티 알약).

  • 물리적 범죄: 가상자산 보유자를 노린 납치, 주거침입 등 물리적 폭력을 동반한 범죄가 2026년 상반기 급증 (데일리시큐).

  • 보안 협력: 이스트시큐리티와 퓨리오사AI가 차세대 K-AI 보안 솔루션 개발을 위한 MOU 체결 (데일리시큐).
