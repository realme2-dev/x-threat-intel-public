1. 현재 주요 사이버보안 트렌드


최근 공격자들은 엣지 장비의 Zero-day 취약점을 악용하여 Web Shell을 배포하거나 내부 네트워크로 침투하는 전략을 강화하고 있습니다. 특히 AI 기술을 활용하여 피싱 캠페인을 정교화하거나, 악성 Custom GPT를 RAT 유포 경로로 활용하는 등 공격의 자동화와 지능화가 두드러집니다(DarkReading). 또한, 공급망 공격이 단순 타이포스쿼팅을 넘어 다단계 C2 체인을 갖춘 형태로 진화하고 있어 오픈소스 패키지 및 개발 환경에 대한 보안 관리가 시급합니다(이스트시큐리티 알약).

2. 주요 위협 행위자 / 캠페인


- Star Blizzard: 러시아 국가 배후 해킹 그룹으로, 'RedFlick'이라는 새로운 기법을 통해 CosmicPulse backdoor를 배포 중(BleepingComputer).
- ShinyHunters: 데이터 절취 및 갈취를 일삼는 그룹으로, 최근 네덜란드 경찰에 의해 핵심 조력자가 체포됨(Krebs on Security).

3. 한국 관련 위협


- 카카오톡 사칭 악성코드: SEO Poisoning을 통해 카카오톡 설치 파일로 위장한 악성코드가 유포 중이며, NSIS, Advanced Installer 등 다양한 패키징 방식을 사용함(AhnLab ASEC).
- Pi Coin 피싱: 암호화폐 계정 보호를 사칭한 스미싱 문자를 통해 지갑 정보를 탈취하는 캠페인 확인(AhnLab ASEC).
- 악성 문자 차단 API: 누리랩과 NICE평가정보가 인터넷 발송 문자 내 악성 URL 사전 차단 API 공급을 시작함(데일리시큐).
