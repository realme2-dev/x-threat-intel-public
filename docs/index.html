1. 현재 주요 사이버보안 트렌드


최근 사이버 위협은 AI 에이전트의 자율성을 악용하거나, AI가 생성한 코드의 취약점을 노리는 방향으로 진화하고 있습니다. 특히 Atlassian Rovo와 같은 AI 어시스턴트가 기업 내부 데이터를 외부로 유출하도록 유도하는 공격이 발견되었으며, AI가 생성한 보안 패치의 절반 이상이 오히려 새로운 취약점을 유발한다는 연구 결과가 보고되었습니다 (TheHackerNews, DarkReading). 또한, 웹메일 인터페이스의 보안을 우회하는 새로운 CSS 공격 기법과, 공급망 공격을 통해 합법적인 소프트웨어 설치 파일을 트로이목마화하는 사례가 지속적으로 확인되고 있습니다 (TheHackerNews, BleepingComputer).

2. 주요 위협 행위자 / 캠페인


- UNC6671: 기존 BlackFile 브랜드에서 Redact, Pink, Helix, Falcon 등으로 브랜드를 변경하며 Vishing 기반의 갈취 활동을 지속 중 (SecurityWeek).
- Head Mare: 패치되지 않은 TrueConf 서버 취약점을 악용하여 클라이언트 설치 파일을 악성 버전으로 교체하는 공급망 공격 수행 (BleepingComputer).
- Larva-26005: 국내 사용자를 대상으로 Xctdoor 악성코드를 유포하는 캠페인 수행 (AhnLab ASEC).
- Lazarus Group: Bybit 거래소로부터 15억 달러 규모의 자산을 탈취한 혐의로 미국 법원에 제소됨 (Crowdfundnews).

3. 한국 관련 위협


- AhnLab ASEC: Larva-26005 공격자의 Xctdoor 유포 및 Larva-24009의 피싱 메일 공격 사례 분석 보고 (AhnLab ASEC, AhnLab ASEC).
- 이스트시큐리티: 국내 정부기관 담당자를 대상으로 한 상품 파손 사칭 스피어피싱 메일 및 AI 에이전트 보안 위협 경고 (이스트시큐리티 알약, 이스트시큐리티 알약).
- 기타: 한국 자동차 부품 제조기업 내부 서버 접근 권한 및 DB 판매 정황 포착 (AhnLab ASEC).

4. 주요 CVE / 취약점


- Metabase SQLi (GHSA-vwf4-m7j8-wcjf): 미인증 SQL Injection, CVSS 10.0, 야생에서 제로데이로 악용 중 (BleepingComputer).
- CVE-2026-64638 (XSS2Shell): WordPress Core Pre-auth XSS to RCE, CVSS 8.9, 공격 체인 공개 (ntsuji 트윗).
- CVE-2026-71851: crypto-js <4.0.0 RCE, CVSS 9.0, 키 복구 가능 (HugoValters 트윗).
- CVE-2026-65400: macOS Screen Sharing 인증 우회, PoC 공개 (connect24h 트윗).

5. IOC 요약


- CVE: GHSA-vwf4-m7j8-wcjf (BleepingComputer), CVE-2026-64638 (ntsuji 트윗), CVE-2026-71851 (HugoValters 트윗).
- 기타: 이번 수집 데이터 내 직접적인 도메인/해시 값은 보안 정책상 생략됨.

6. 즉각 대응 권고


- Metabase 업데이트: Metabase 인스턴스를 즉시 최신 버전으로 패치하여 SQLi 취약점 대응.
- Atlassian Rovo 설정 검토: AI 어시스턴트의 데이터 접근 권한을 제한하고, 외부 서버로의 데이터 전송 가능성 모니터링.
- 공급망 보안 강화: 소프트웨어 설치 파일의 무결성 검증(디지털 서명 확인) 절차를 강화하고, 신뢰할 수 없는 출처의 실행 파일 다운로드 차단.
