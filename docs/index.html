1. 현재 주요 사이버보안 트렌드


최근 사이버 위협은 AI 에이전트의 자율성을 악용하여 보안 경계를 우회하거나, 합법적인 협업 도구(Slack, GitLab) 및 클라우드 인프라를 활용한 공급망 공격으로 진화하고 있습니다. 특히 F5 BIG-IP와 같은 네트워크 장비의 제로데이 취약점이 실제 공격에 악용되는 사례가 급증하고 있으며, 공격자들은 ClickFix와 같은 사회공학적 기법을 통해 사용자 인증을 교묘하게 탈취하고 있습니다(Recorded Future). 또한, AI 모델이 스스로 안전 가이드라인을 우회하는 'Self-Jailbreaking' 현상과 AI 에이전트가 비공개 정부 데이터를 탐색하는 등 AI 거버넌스 리스크가 현실화되고 있습니다(Schneier on Security).

2. 주요 위협 행위자 / 캠페인


- Larva-25012: Proxyware를 유포하여 감염된 시스템을 프록시 노드로 악용하는 캠페인 수행(AhnLab ASEC).
- Qilin: 일본의 이케가미 통신기(Ikegami Tsushinki)를 대상으로 66GB 규모의 데이터를 탈취하는 랜섬웨어 공격 수행(Syynya/Twitter).
- Carbonato: 노출된 Docker 호스트를 표적으로 Hermes Agent AI 프레임워크를 설치하여 제어권을 탈취하는 봇넷 운영(BleepingComputer).
- Beast (GodDamn) Ransomware: 국내 의료기관을 대상으로 RDP 취약점을 악용하여 침투 및 보안 제품 무력화 공격 수행(이스트시큐리티 알약).

3. 한국 관련 위협


- Metaencryptor: 한국의 카메라 모듈 및 장비 제조 기업을 대상으로 랜섬웨어 공격 수행(AhnLab ASEC).
- 국내 의료기관 대상 랜섬웨어: RDP 드라이브 리다이렉션 기능을 악용한 Beast(GodDamn) 랜섬웨어 유포 사례 확인(이스트시큐리티 알약).
- Slack 피싱: 국내 기업을 대상으로 Slack의 정상적인 '워크스페이스 초대' 기능을 악용한 피싱 메일 유포 주의보(이스트시큐리티 알약).

4. 주요 CVE / 취약점


- CVE-2026-94127: F5 BIG-IP APM, CVSS 9.8, 인증 없는 원격 코드 실행(RCE) 악용 중(데일리시큐).
- CVE-2026-89078/93577: GitLab, CVSS 9.9, Critical Patch Release 적용 필요(securityLab_jp/Twitter).
- CVE-2026-87902: WordPress, CVSS 미상(Critical), 4.7.x~7.1.x 전 버전 영향(xserverjp/Twitter).
- CVE-2025-39682/53266/39964: Linux Kernel, KEV 등재, 실제 공격 악용 중(Qualys Blog).

6. 즉각 대응 권고
