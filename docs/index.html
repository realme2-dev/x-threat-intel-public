- Ransom Cartel: Maksim Silnikau가 운영한 랜섬웨어 조직으로, 최소 18개 기업을 공격한 혐의로 운영자가 16년 형을 선고받음(BleepingComputer).
- TeamPCP: 오픈소스 소프트웨어 공급망을 타겟으로 하는 공격 그룹으로, 2020년부터 장기간 운영된 인프라를 보유함(CyberScoop).
