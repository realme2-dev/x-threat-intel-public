1. 현재 주요 사이버보안 트렌드


최근 사이버 공격은 AI 에이전트를 활용하여 공격 주기를 획기적으로 단축하고 있으며, 10시간 이내에 기업 네트워크 침투 및 데이터 탈취를 완료하는 사례가 보고되고 있습니다 (Unit42). 또한, 공격자들은 이메일 보안 필터를 우회하기 위해 Unicode 문자를 사용하는 ASCII smuggling 기법을 적극 도입하고 있으며, 블록체인 스마트 컨트랙트에 악성 페이로드를 저장하여 유포하는 등 인프라를 다변화하고 있습니다 (BleepingComputer). 더불어 MikroTik 라우터와 같은 네트워크 장비의 SSH 취약점을 노린 인증 우회 공격이 활발히 진행 중이므로 즉각적인 패치가 요구됩니다 (TheHackerNews).

2. 주요 위협 행위자 / 캠페인


- Toy Ghouls: HiveMQ MQTT 브로커와 Matrix 프로토콜을 C2 서버로 활용하는 새로운 백도어 캠페인 수행 (Securelist)
- Mirage Kitten: Node.js 기반의 NodeRabbit, JavaScript 기반의 PollCat 등 신규 악성코드를 사용하여 중동 및 아프리카의 항공·핀테크 분야 타겟팅 (Securelist)
- TeamPCP: 소프트웨어 공급망 공격을 주도한 혐의로 호주에서 주요 조직원 2명 체포 (Krebs on Security)

3. 한국 관련 위협


- Black X: 한국 자동차 부품 제조기업을 대상으로 랜섬웨어 공격 수행 (AhnLab ASEC)
- 원격 제어 도구 악용: 국내 시스템을 대상으로 Radmin 및 UltraVNC를 설치하여 제어권을 탈취하는 공격 사례 확인 (AhnLab ASEC)
- 스피어피싱: 정부기관 담당자를 사칭한 상품 파손 클레임 메일 유포, 정상 서명된 Excel 파일과 악성 DLL을 결합한 형태 (이스트시큐리티 알약)

4. 주요 CVE / 취약점
