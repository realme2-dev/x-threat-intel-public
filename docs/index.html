1. 현재 주요 사이버보안 트렌드


최근 사이버 보안 환경은 NGINX, Apache Roller, Java 등 핵심 인프라 소프트웨어의 치명적인 RCE 취약점이 연이어 발견되며 'Vulnpocalypse' 양상을 보이고 있습니다. 특히 AI를 활용한 공격 자동화와 더불어, 공급망 공격(Supply Chain Attack)을 통해 합법적인 도구를 악용하는 방식이 고도화되고 있습니다(Unit42). 또한, 다크웹 내에서 랜섬웨어 그룹이 '컨설팅'을 위장한 강압적 감사(Forced Audit) 모델을 도입하는 등 수익화 전략이 더욱 정교해지고 있습니다(Securelist).

2. 주요 위협 행위자 / 캠페인


- Star Blizzard: 탈취된 데이터를 활용해 기업 임직원을 사칭하는 피싱 공격 수행(SecurityWeek).
- Cold Relic: 클라우드 침해 사고에서 확보한 데이터를 기반으로 사회공학적 기법을 결합한 2차 공격 수행(DarkReading).
- AuditTeam: 'OpsAgent' 프레임워크를 사용하여 랜섬웨어 피해 기업을 대상으로 컨설팅 비용 명목의 금전을 갈취하는 모델 운영(Securelist).
- Iranian Cyber Groups: 20여 개 이상의 그룹이 상호 협력하여 네트워크 접근 권한을 공유하고 파괴적인 공격을 수행(DarkReading).

3. 한국 관련 위협


- Java4Shell (CVE-2026-114938): 엔키화이트햇이 내부 점검 도구를 배포하며 국내 서버 환경의 취약점 점검을 권고함(데일리시큐).
- NGINX2Root: 티오리(Theori) Xint 연구팀이 NGINX 취약점 5건을 공개하고, 커널 취약점과 결합한 root 권한 탈취 시나리오를 제시함(데일리시큐).
- Pi Network 스미싱: 암호화폐 보상을 미끼로 한 스미싱이 한국 사용자 대상으로 유포 중(이스트시큐리티 알약).

4. 주요 CVE / 취약점

- CVE-2026-114938: Java4Shell, CVSS 9.2, 패치 배포 완료(AhnLab ASEC)
