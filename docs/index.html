최근 공격자들은 MFA를 우회하기 위해 Device Code Phishing 기법을 적극 활용하고 있으며, 이는 전년 대비 1,500% 증가한 수치를 보입니다 (DarkReading). 또한, AI 에이전트와 LLM을 활용한 자동화된 취약점 탐색 및 공격이 산업화 단계에 진입했으며, 오픈소스 생태계 내 대규모 공급망 공격이 빈번하게 발생하고 있습니다 (Unit42). 마지막으로, 신뢰할 수 있는 소프트웨어 업데이트나 RMM 도구를 악용하여 지속적인 원격 접근을 유지하는 사회공학적 기법이 고도화되고 있습니다 (TheHackerNews).
