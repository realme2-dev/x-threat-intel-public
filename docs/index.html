1. 현재 주요 사이버보안 트렌드


최근 사이버 위협 환경은 생성형 AI를 활용한 공격 기법의 고도화와 자동화된 공격 도구의 확산이 두드러집니다. 공격자들은 AI 모델의 제어권을 우회하거나, AI를 활용해 취약점을 탐색하고 악성코드를 생성하는 등 공격 효율을 극대화하고 있습니다 (Check Point Research). 또한, 오픈소스 공급망 침해와 정상적인 클라우드 서비스(GitHub, Telegram 등)를 C2 인프라로 악용하는 전략이 APT 그룹 사이에서 보편화되고 있습니다 (AhnLab ASEC). 마지막으로, API 인증 우회 및 경로 탐색 취약점 등 인프라 핵심 구성 요소에 대한 제로데이 공격이 활발히 보고되고 있어, 실시간 패치 적용과 지속적인 보안 모니터링의 중요성이 강조됩니다 (DarkReading).

2. 주요 위협 행위자 / 캠페인


  • Transparent Tribe (APT36/Earth Karkaddan): 인도 및 주변국 정부/국방 기관을 타겟으로 Rust 기반의 새로운 백도어를 배포하며, C2 통신에 개인 GitHub 저장소를 악용함 (TheHackerNews).

  • WaterPlum: 구직자를 가장하여 전 세계 30,000대 이상의 기기를 감염시키고 암호화폐 탈취 및 정보 유출을 시도함 (CyberScoop).

  • NightEagle: GhostContainer 백도어를 사용하여 러시아 기업을 타겟팅하며, Active Directory 취약점을 악용함 (Securelist).

  • FamousSparrow: 새로운 플래그십 백도어인 SparroWocky를 사용하여 공격 수행 (WeLiveSecurity).


    • 3. 한국 관련 위협


  • 국가정보원: 국제 사이버훈련 'APEX 2026'에 AI 방어팀을 투입하여 실시간 자동 대응 체계 검증 (데일리시큐).

  • 해사안전기본법 개정안: 선박 사이버공격 대응을 위한 법적 체계 구축 추진 (데일리시큐).

  • 랜섬웨어 유포: 사설 HTS 프로그램 'UBP 에셋'을 통한 랜섬웨어 유포 확인 (AhnLab ASEC).

  • 의료기관 타겟: RDP를 악용한 Beast(GodDamn) 랜섬웨어 공격 사례 보고 (이스트시큐리티 알약).


    • 4. 주요 CVE / 취약점


  • CVE-2026-76460: Cisco ISE API 인증 우회, CVSS 10.0, 활발히 악용 중 (DarkReading).

  • CVE-2026-21858: n8n 인증되지 않은 파일 읽기 및 RCE, CVSS 10.0 (PadhiyarRushi/Twitter).

  • CVE-2026-41089: Windows Netlogon CLDAP 스택 버퍼 오버플로우, CVSS 9.8 (PadhiyarRushi/Twitter).

  • CVE-2026-91843: Check Point Security Management Server RCE, CVSS 9.8 (snakeyesV1/Twitter).

  • CVE-2026-85706: GitLab 저장소 커밋 API 경로 탐색 취약점, 심각도 높음 (이스트시큐리티 알약).


    • 5. IOC 요약


  • CVE: CVE-2026-76460 (DarkReading), CVE-2026-85706 (이스트시큐리티 알약)


    • 6. 즉각 대응 권고


  • Cisco ISE 패치: CVE-2026-76460에 대해 즉시 패치(3.1 P12 / 3.2 P11)를 적용하고, 외부 노출된 API 엔드포인트 접근을 차단하십시오.

  • RDP 보안 강화: 의료기관 및 기업 내 RDP 사용 시 다중 인증(MFA)을 필수 적용하고, 불필요한 드라이브 리다이렉션 기능을 비활성화하십시오.

  • 공급망 검토: GitHub 등 외부 저장소에서 다운로드한 도구의 무결성을 검증하고, 특히 사설 HTS나 비공식 소프트웨어 설치를 엄격히 통제하십시오.
