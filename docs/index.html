1. 현재 주요 사이버보안 트렌드


최근 사이버 위협은 AI 기술을 악용한 자동화된 공격과 오픈소스 공급망 공격이 결합되어 더욱 정교해지고 있습니다. 특히 GitLab AI Gateway와 같은 AI 인프라의 취약점을 노린 RCE 공격이 급증하고 있으며, 공격자들은 기존의 전통적인 기법 대신 신뢰받는 협업 도구나 API 권한 검증 허점을 파고드는 방식을 선호합니다 (TheHackerNews). 또한, 보안 팀의 대응 속도를 앞지르는 'Machine-Speed' 공격에 대응하기 위해 자율 방어 플랫폼과 AI 기반의 위협 탐지 체계 도입이 필수적인 과제로 떠오르고 있습니다 (Recorded Future).

2. 주요 위협 행위자 / 캠페인


- Warlock: SharePoint 취약점을 악용하여 수자원, 통신사, 대학 등 공공 및 교육 인프라를 타겟팅하는 중국 연계 랜섬웨어 그룹 (BleepingComputer).
- Antino: Outlook과 OneDrive를 C2 채널로 활용하여 아시아 지역 정부 및 정책 기관을 대상으로 스파이 활동을 수행하는 중국 연계 그룹 (TheHackerNews).
- KillSec: 2년 미만의 기간 동안 약 500개 조직을 공격한 10대 중심의 갈취 그룹으로, 최근 인프라가 압수되고 핵심 멤버가 체포됨 (CyberScoop).

3. 한국 관련 위협


- 금융권 AI 자율 침투 공격: 신한은행을 포함한 국내 금융권에서 AI 자율 침투 도구를 이용한 API 권한 검증 허점 공격이 발생하여 고객 정보 유출 사고가 이어지고 있음 (데일리시큐).
- 카카오톡 사칭 악성코드: SEO Poisoning을 통해 카카오톡 설치 파일로 위장한 악성코드가 국내 유포 중이며, NSIS/Advanced Installer 등을 순차적으로 사용하는 변종이 확인됨 (AhnLab ASEC).
- 통신/메일 게이트웨이 타겟팅: BPFDoor, Rekoobe, AVERAT 등의 악성코드가 한국과 대만의 통신 에지 장비 및 메일 보안 게이트웨이를 공격 중 (DFIR_Radar).

4. 주요 CVE / 취약점


- CVE-2026-90970: GitLab AI Gateway RCE, CVSS 9.9, 즉시 업데이트 권고 (iss_kk_official).
- CVE-2026-104286: FortiMail Path Traversal/Arbitrary File Write, CVSS 9.8, 실제 악용 중 (Unit42).
- CVE-2026-63292: Apache HTTP Server RCE, CVSS 9.8, 패치 적용 필요 (Netlas_io).
- CVE-2026-61821: PostgreSQL pg_partman Privilege Escalation, CVSS 8.5, 즉시 업데이트 권고 (DFIR_Lab).
- CVE-2026-61818: PostgreSQL pg_partman SQL Injection, CVSS 8.5, 즉시 업데이트 권고 (DFIR_Lab).

5. IOC 요약

6. 즉각 대응 권고


- GitLab AI Gateway 점검: Self-Hosted 환경의 AI Gateway를 최신 버전(19.2.4/19.3.2/19.4.1)으로 즉시 업데이트하십시오.
- FortiMail 보안 강화: CVE-2026-104286 대응을 위해 관리자 페이지의 외부 노출을 즉시 차단하고, 시스템 파일 변조 여부를 점검하십시오.
- 금융/공공 API 보안 감사: AI 자율 침투 공격에 대비하여 API 권한 검증 로직을 재검토하고, 비정상적인 대량 데이터 접근 로그를 모니터링하십시오.
