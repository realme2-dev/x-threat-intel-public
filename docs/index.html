1. 현재 주요 사이버보안 트렌드


최근 사이버 위협은 AI 기술을 활용한 공격의 고도화와 자동화가 핵심 트렌드로 자리 잡고 있습니다. 특히 'Agentic AI'가 취약점 탐색부터 공격 코드 생성, 표적 선정까지 수행하며 공격의 속도와 효율성을 극대화하고 있으며, 이로 인해 기존의 인간 중심 보안 대응 체계가 한계에 직면했습니다 (Qualys Blog). 또한, OT(Operational Technology) 환경을 겨냥한 공격이 민간 셀룰러 네트워크(Private APN)를 우회 경로로 활용하는 등 인프라 보안의 취약점을 정밀 타격하는 사례가 보고되고 있습니다 (TheHackerNews). 공급망 공격 역시 WordPress 플러그인과 같은 소프트웨어 생태계를 직접 오염시키는 방식으로 진화하고 있어, AI 기반의 방어 체계와 실시간 검증 서비스의 중요성이 강조되고 있습니다 (BleepingComputer).

2. 주요 위협 행위자 / 캠페인


- Iran-linked Threat Actors: 다수의 미국 주(State) 수자원 시스템을 대상으로 인터넷에 노출된 PLC를 공격 (DarkReading).
- Handala: 북미 지역 인터넷 서비스 제공업체의 핵심 인프라를 침해하여 대규모 장애를 유발했다고 주장 (AhnLab ASEC).
- Aeternum: Polygon 블록체인 스마트 컨트랙트를 C2 인프라로 활용하는 봇넷 로더 운영 (Unit42).
- ChainDrop: npm 공급망을 통해 유포되는 자가 전파형 웜으로, GitHub Actions 러너의 시크릿을 탈취하고 Ethereum 스마트 컨트랙트를 C2 라우팅에 활용 (Unit42).
