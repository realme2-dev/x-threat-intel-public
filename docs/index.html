1. 현재 주요 사이버보안 트렌드


최근 사이버 위협은 AI를 활용한 공격 자동화와 사회 공학적 기법의 고도화가 핵심입니다. 공격자들은 AI 모델을 악용하여 대규모 피싱 이메일을 생성하거나, ClickFix 및 TerminalFix와 같은 기법을 통해 사용자가 직접 악성 명령을 실행하도록 유도하는 등 공격 성공률을 높이고 있습니다(AhnLab ASEC). 또한, 소프트웨어 공급망 공격과 더불어 취약한 LLM API 게이트웨이를 노리는 공격이 증가하고 있으며, 기업 SOC는 AI 에이전트가 생성하는 비정상적인 경보 대응에 어려움을 겪고 있습니다(TheHackerNews).

2. 주요 위협 행위자 / 캠페인


- UNC3569: 중국 연계 해킹 그룹으로, Sogou Input Method의 취약점(CVE-2026-51990)을 악용하여 GRAYRABBIT 백도어를 설치함(데일리시큐).
- Toy Ghouls: HiveMQ MQTT 브로커 및 Matrix 프로토콜을 C2 서버로 활용하는 새로운 백도어를 배포 중(Securelist).
- Mirage Kitten: Node.js 기반의 NodeRabbit, JavaScript 기반의 PollCat 등 신규 악성코드 패밀리를 사용하여 중동 및 아프리카의 항공·핀테크 분야를 타겟팅함(Securelist).
- Kimsuky: 기능별로 C2 서버를 분산 운용하는 새로운 LNK 악성코드를 국내 금융 문서로 위장하여 유포 중(이스트시큐리티 알약).

3. 한국 관련 위협


- Kimsuky 그룹: 국내 금융 관련 문서로 위장한 LNK 악성코드를 유포하여 정보 탈취 시도(이스트시큐리티 알약).
- Sogou 입력기 취약점: 국내에서도 널리 사용되는 Sogou Input Method의 CVE-2026-51990 취약점 악용 사례 확인(데일리시큐).
- 기타: 이번 수집 데이터 내 한국어 트윗([KR])은 발견되지 않았으나, 국내 보안 블로그를 통해 ClickFix/TerminalFix 공격 및 랜섬웨어 위협이 지속적으로 경고되고 있음.

4. 주요 CVE / 취약점


- CVE-2026-51990: Sogou Input Method RCE 취약점, 실제 악용 중(BleepingComputer).
- CVE-2026-85102 / CVE-2026-85103: Check Point VPN 취약점, 즉각적인 악용 가능성 경고(BleepingComputer).
- CVE-2026-85046: Google Chrome V8 엔진 Type Confusion 취약점, 실제 악용 중(이스트시큐리티 알약).

5. IOC 요약


- CVE:
- CVE-2026-51990 (BleepingComputer)
- CVE-2026-85102, CVE-2026-85103 (BleepingComputer)
- CVE-2026-85046 (이스트시큐리티 알약)

6. 즉각 대응 권고


- 패치 적용: Sogou Input Method, Check Point VPN, Google Chrome의 최신 보안 업데이트를 즉시 적용하십시오.
- 사용자 교육: ClickFix/TerminalFix 공격 방지를 위해 브라우저나 문서 실행 시 나타나는 '보안 인증' 또는 '터미널 명령 실행' 팝업을 무조건 신뢰하지 않도록 교육하십시오.
- 모니터링 강화: Kimsuky 그룹의 LNK 파일 유포 정황을 고려하여, 비정상적인 PowerShell 실행 및 외부 C2 통신 시도를 탐지하는 EDR 정책을 강화하십시오.
