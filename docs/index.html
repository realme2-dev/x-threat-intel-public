1. 현재 주요 사이버보안 트렌드


최근 사이버 위협 환경은 LLM 기반의 Agentic AI가 공격의 전 과정(정찰, 취약점 탐색, 침투)을 자율적으로 수행하는 단계로 진화하고 있으며, 이는 기업 보안 체계에 심각한 도전 과제가 되고 있습니다(Unit42). 특히 하드웨어 지갑의 펌웨어 취약점이나 광고 스크립트 변조를 통한 암호화폐 탈취 등 금융 자산을 직접 노리는 공격이 급증하고 있습니다(TheHackerNews). 또한, 저가형 IoT 기기(TV 박스 등)를 좀비 네트워크화하여 광고 사기나 프록시 노드로 악용하는 사례가 지속적으로 보고되고 있습니다(BleepingComputer).

2. 주요 위협 행위자 / 캠페인


- Toy Ghouls: Securelist에 따르면, Windows, Linux, ESXi 시스템을 대상으로 하는 GenieLocker 랜섬웨어를 유포하며 금전적 이득을 취하는 그룹입니다.
- Larva-26009: AhnLab ASEC에 의해 식별되었으며, MS-SQL 서버를 타겟으로 XMRig 코인 마이너와 GotoHTTP, SoftEther VPN을 설치하여 원격 제어 환경을 구축합니다.
- 중국어 사용 해커(knaithe/KnYu): Unit42 분석 결과, 텔레그램을 통해 AI 모델(DeepSeek)에 명령을 내려 취약한 시스템을 자동화 공격하는 캠페인을 수행 중입니다.

3. 한국 관련 위협


- 국가 배후 해킹 조직: AhnLab ASEC은 국가 배후 해킹 조직과 Gunra 랜섬웨어 그룹 간의 연계성을 분석한 'Operation Double Barrel' 권고문을 발표했습니다.
- 호텔 와이파이 악성코드 유포: 데일리시큐에 따르면, 호텔 공용 와이파이를 장악하여 이용자에게 가짜 브라우저 업데이트를 유도하고, PC의 마이크·웹캠·키보드를 감시하는 사이버 스파이 공격이 확인되었습니다.
