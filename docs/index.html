1. 현재 주요 사이버보안 트렌드


최근 사이버 위협은 AI 모델을 활용한 취약점 탐색 및 자동화된 공격이 고도화되고 있으며, 특히 웹 백엔드 런타임(PHP, Node.js)의 치명적 취약점을 악용한 공급망 및 서버 공격이 급증하고 있습니다(AhnLab ASEC). 또한, 생성형 AI를 사칭한 악성 실행 파일 배포와 프롬프트 인젝션을 통한 에이전트 공격이 실질적인 위협으로 부상했습니다(Check Point Research). 대규모 암호화폐 탈취 시도와 같은 고액 자산 타겟팅 공격이 지속되고 있으며, 공격자들은 AI를 활용해 탈취 정보를 실시간 분석하고 랜섬웨어 기능을 결합하는 등 공격 효율을 극대화하고 있습니다(데일리시큐).

2. 주요 위협 행위자 / 캠페인


- Lazarus Group: 암호화폐 거래소 Binance를 대상으로 약 58억 달러 규모의 대규모 해킹을 시도한 것으로 추정되며, 온체인 데이터 분석을 통해 관련 정황이 포착됨(BleepingComputer).
- VAPOR PANDA: AI 기반의 ARTEX 도구를 사용하여 글로벌 첩보 캠페인을 수행하는 것으로 확인됨(Crowdstrike Blog).
- Noname057: 이탈리아 등 유럽 지역을 타겟으로 하는 DDoS 공격 활동이 지속적으로 보고됨(트렌드 키워드 및 해시태그 기반).

3. 한국 관련 위협


- 금융권 악성코드: 2026년 9월 기준 국내 금융권 대상 Phishing 공격이 증가하고 있으며, Dropper/Downloader를 통한 Infostealer 유포가 주요 위협으로 확인됨(AhnLab ASEC).
- 배송 사칭 공격: 생성형 AI를 활용해 제작된 배송 파손 민원 사칭 메일을 통해 PureRAT 악성코드가 유포되고 있어 사용자 주의가 요구됨(이스트시큐리티 알약).
- 방화벽 취약점: PAN-OS 취약점(PHP2Shell)을 악용한 공격이 국내 기업 및 공공기관을 대상으로 확인되어 긴급 점검이 권고됨(데일리시큐).

4. 주요 CVE / 취약점


- CVE-2026-98432: Linux Kernel TCP Flaw, CVSS 9.8, 실제 악용 가능성 높음(TheHackerNews).
- CVE-2026-109618 / CVE-2026-109619: PHP2Shell RCE, Critical, 실제 방화벽 및 웹 서버 공격 확인(Unit42).
- CVE-2026-111497: Node.js Brotli Decoder RCE, Critical, 'Node2Shell'로 명명(AhnLab ASEC).
- CVE-2026-91403: Oracle Java TLS 구현 취약점, 긴급 보안 경보 발령(이스트시큐리티 알약).
