1. 현재 주요 사이버보안 트렌드


최근 사이버 위협은 생성형 AI를 활용한 공격 자동화와 대규모 피싱 캠페인으로 고도화되고 있습니다. 특히 공격자들은 AI 모델을 악용하여 악성코드 분석을 우회하거나, 대량의 개인 맞춤형 사기 메일을 생성하는 등 공격 효율을 극대화하고 있습니다(DarkReading). 또한, 소프트웨어 공급망 보안과 인증 시스템(Passkey, SSO)을 노린 사회공학적 기법이 증가하고 있으며, AI 모델 자체의 취약점(Prompt Injection, Distillation)을 이용한 지식 탈취 시도가 주요 이슈로 부상했습니다(Anthropic).

2. 주요 위협 행위자 / 캠페인


- Moonshot AI (및 기타 중국 AI 연구소): Anthropic의 Claude 모델을 무단으로 증류(Distillation)하여 자사 서비스에 우회 적용한 정황 포착(TheHackerNews).
- ShinyHunters / Helix: Passkey 및 SSO 테마의 사회공학적 기법을 통해 Microsoft 365 계정 탈취 시도(BleepingComputer).
- Toy Ghouls: HiveMQ MQTT 브로커 및 Matrix 프로토콜을 C2로 사용하는 새로운 백도어 유포(Securelist).
- Kimsuky: 기능별 C2 서버를 분산 운용하는 새로운 LNK 악성코드 유포(이스트시큐리티 알약).
- Mirage Kitten: Node.js 기반의 NodeRabbit 및 JavaScript 기반의 PollCat 백도어를 사용하여 중동/아프리카 지역 타겟팅(Securelist).

3. 한국 관련 위협


- 티빙 개인정보 유출: 모의해킹에서 발견된 보안 취약점을 방치하여 발생한 해킹 사고(트윗).
- 공군 국방망 AI 플랫폼 구축: 시선AI가 국방망 AI 코딩 및 보안 자동화 플랫폼 사업 수주(데일리시큐).
- LegionLoader: ClickFix 방식을 통해 가짜 Cloudflare CAPTCHA 화면으로 악성 PowerShell 실행 유도(AhnLab ASEC).
- 빗썸 사칭 악성코드: AI 자동매매 도구로 위장하여 API 키 및 시드 구문 탈취 시도(트윗).

4. 주요 CVE / 취약점


- CVE-2026-85706: GitLab Path Traversal 취약점, CVSS 10.0(Critical), 인증되지 않은 원격 파일 읽기 가능, 즉시 패치 권고(TheHackerNews).
- CVE-2026-85046: Google Chrome V8 엔진 Type Confusion 취약점, 원격 코드 실행 가능, 실제 공격 악용 중(이스트시큐리티 알약).

5. IOC 요약


- CVE: CVE-2026-85706 (TheHackerNews), CVE-2026-85046 (이스트시큐리티 알약)

6. 즉각 대응 권고


- GitLab 업데이트: CVE-2026-85706 패치를 즉시 적용하고, 자가 호스팅 서버의 접근 로그를 검토하여 비정상적인 파일 접근 시도 확인.
- 브라우저 보안: Chrome 브라우저를 최신 버전으로 업데이트하여 CVE-2026-85046 악용 방지.
- ClickFix 주의: CAPTCHA 인증을 요구하는 웹사이트에서 PowerShell 명령 실행을 유도하는 경우 절대 실행하지 않도록 사용자 교육 및 EDR 탐지 정책 강화.
