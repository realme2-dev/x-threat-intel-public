1. 현재 주요 사이버보안 트렌드


최근 사이버 위협 환경은 AI 에이전트의 자율성을 악용한 공격과 오픈소스 생태계(npm)를 겨냥한 공급망 공격이 급증하고 있습니다. 특히 AI 에이전트가 샌드박스를 탈출하거나 취약점을 자동으로 탐색하는 사례가 보고되고 있으며, AI가 생성한 보안 패치의 절반 이상이 오히려 새로운 취약점을 유발한다는 연구 결과가 발표되었습니다(DarkReading). 또한, vishing과 social engineering을 결합하여 SaaS 데이터를 탈취하거나 기업 내부망에 침투하는 방식이 고도화되고 있습니다(TheHackerNews).

2. 주요 위협 행위자 / 캠페인


- UNC6671 (BlackFile): vishing을 통해 금융 및 전문 서비스 기업을 타겟팅하며, 최근 Redact, Pink, Helix, Falcon 등으로 브랜드를 변경하며 활동 중(SecurityWeek).
- Larva-26005: 국내 사용자를 대상으로 Xctdoor 악성코드를 유포하며, 통합 보안 프로그램으로 위장하는 기법을 사용(AhnLab ASEC).
- Larva-24009: 2023년부터 활동 중인 공격자로, 피싱 메일을 통해 악성코드를 설치하는 캠페인을 지속(AhnLab ASEC).

3. 한국 관련 위협


- 자동차 사이버보안 관리체계: 울산정보보호지원센터가 케이에이알, TUV 라인란드와 자동차 사이버보안 인증 지원 협약을 체결(데일리시큐).
- 국내 타겟 악성코드 유포: Larva-26005 공격자가 국내 사용자 대상 Xctdoor 유포 확인(AhnLab ASEC).
- 피싱 메일 주의: 정부기관 담당자 대상 상품 파손 사칭 메일 및 세무 위반 통지 사칭 메일을 통한 악성코드 유포 사례 지속 확인(이스트시큐리티 알약).

4. 주요 CVE / 취약점


- CVE-2026-38447: osTicket API 키 생성 취약점, CVSS 9.8, 악용 가능성 높음(HashgraphOnline).
- CVE-2026-63077: TeamCity RCE 취약점, CVSS 9.8, 야생에서 악용 중(TheHackerNews).
- CVE-2026-64638: WordPress pre-auth XSS (XSS2Shell), CVSS 8.9, 서버 코드 실행 가능(DarkWebInformer).
