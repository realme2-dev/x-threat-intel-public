1. 현재 주요 사이버보안 트렌드


최근 공격자들은 LLM을 활용한 프롬프트 엔지니어링 기법(PuzzleMask 등)을 통해 보안 정책을 우회하거나, ClickFix 및 TerminalFix와 같이 사용자의 부주의를 유도하여 악성 명령을 직접 실행하게 만드는 사회공학적 기법을 고도화하고 있습니다. 또한, 소프트웨어 공급망 공격이 지속되는 가운데 JFrog Artifactory와 같은 빌드 파이프라인 인프라를 직접 타겟팅하여 관리자 권한을 탈취하는 사례가 보고되고 있습니다 (TheHackerNews). AI 에이전트가 취약점을 탐색하고 공격 타임라인을 단축시키는 현상이 가속화됨에 따라, 방어 측에서도 AI 기반의 자동화된 보안 대응 플랫폼 도입이 필수적인 과제로 부상했습니다 (Schneier on Security).

2. 주요 위협 행위자 / 캠페인


- UNC3569: Sogou Input Method 취약점을 악용하여 GRAYRABBIT 백도어를 배포하는 중국 연계 그룹 (TheHackerNews)
- GoldFactory: Android Work Profile 기능을 악용하여 Gigabud Trojan을 유포하는 모바일 뱅킹 악성코드 캠페인 (DarkReading)
- Kimsuky: 기능별 C2 서버를 분산 운용하는 새로운 LNK 악성코드를 국내 금융 문서로 위장하여 유포 (이스트시큐리티 알약)
- Toy Ghouls: HiveMQ MQTT 및 Matrix 프로토콜을 C2로 사용하는 신규 백도어 유포 (Securelist)

3. 한국 관련 위협


- 시선AI: 대한민국 공군 국방망 대상 AI 코딩 및 Secure Code 자동점검 에이전트 구축 사업 수주 (데일리시큐)
- 금융보안원: 보이스피싱 대응을 위한 AI 기반 플랫폼 'ASAP' 활용 설명회 개최 (데일리시큐)
- 악성코드: Kimsuky 그룹이 국내 금융 문서로 위장한 LNK 악성코드를 유포 중이며, LegionLoader가 ClickFix 방식으로 국내 사용자 타겟팅 (이스트시큐리티 알약, AhnLab ASEC)
