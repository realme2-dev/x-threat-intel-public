1. 현재 주요 사이버보안 트렌드


최근 보안 위협은 웹 백엔드 런타임(PHP, Node.js)의 취약점을 악용하여 서버 권한을 탈취하는 공격이 지속되고 있으며, 특히 AI 도구 및 API 키를 노린 공급망 공격이 급증하고 있습니다(AhnLab ASEC). 공격자들은 AI 에이전트 기술을 활용해 침투 속도를 높이고 있으며, 취약한 클라우드 설정이나 API 키 탈취를 통해 민감 데이터에 접근하는 사례가 빈번합니다(BleepingComputer). 또한, 가상자산 거래소를 겨냥한 대규모 해킹과 랜섬웨어 공격이 여전히 활발하며, 특히 북한 연계 위협 행위자들의 활동이 두드러집니다(데일리시큐).

2. 주요 위협 행위자 / 캠페인


- TraderTraitor (North Korea): Binance를 포함한 가상자산 거래소를 타겟으로 약 $6.43 Billion 규모의 자산을 탈취한 것으로 FBI 공식 지목됨(TheHackerNews).
- Vapor Panda (China-backed): 에이전트 AI 펜테스팅 도구를 사용하여 11일 만에 140개 이상의 민감 타겟을 공격함(CyberScoop).
- Noname057: 독일 정부 및 방산, 법 집행 기관 웹사이트를 대상으로 DDoS 공격 수행(codabar).
- UTA0576: Ivanti Connect Secure의 3개 취약점을 체이닝하여 패치된 시스템에서도 인증되지 않은 root 권한 획득(DarkWebInformer).

3. 한국 관련 위협


- 북한 연계 가상자산 해킹: FBI는 Binance 해킹 사건의 배후로 북한을 지목했으며, 체이널리시스는 올해 가상자산 해킹 피해의 89%가 북한과 연계된 것으로 분석함(데일리시큐).
- C3RB3R 랜섬웨어: 시놀로지(Synology) NAS 사용자를 노린 공격이 국내에서 집중 보고됨(이스트시큐리티 알약).
- PureRAT 유포: 배송 파손 민원을 사칭한 피싱 메일을 통해 PureRAT 악성코드 유포 확인(이스트시큐리티 알약).

4. 주요 CVE / 취약점


- LXD/MicroCloud Flaw (CVSS 10.0): 신뢰받는 클라이언트의 private key 없이 HTTPS API를 통해 인증 우회 가능(TheHackerNews).
- CVE-2026-109618, CVE-2026-109619 (PHP2Shell): 웹 서버 및 CMS 시스템을 타겟으로 하는 RCE 취약점(Unit42).
- CVE-2026-111497 (Node2Shell): Node.js의 Brotli 디코더 내 out-of-bounds write 취약점(AhnLab ASEC).
- CVE-2026-58882 (SMS of Death): Android 기기를 원격으로 강제 종료시킬 수 있는 취약점(BleepingComputer).
- CVE-2026-91403: Oracle Java JSSE 컴포넌트의 TLS 인증서 검증 우회 취약점(이스트시큐리티 알약).
